**Why:** user wants the original Dock visible on the pearOS screen (screenshot).
**How to apply:**
- Gotchas: stack scripts must pkill svc-stub/xpc-stub too (stale ones filled swap and OOM-killed apps); use `sed -i ''` on FreeBSD; the darwinator build dir on the VM is /root/darwinator (not /root/dnew); kldunload needs all stack processes killed first.
- lldb attach breaks the workqueue emulation (SIGILL in libpthread): don't use it past startup.
- QEMU monitor `screendump` fails ("no surface") with the GL display; wswins needs `WS_SOCKET=/tmp/wsd.sock`; wsd runs without -t so its screenshot request is refused.
- lsd-stub: NSXPC messages (`replysig`) must NOT be answered; check-in 500 needs the LSASN marker uuid (see lsd-stub/README.md).
- Missing-file hunting: kern.darwinator.debug=2 trace, log dmesg to a file in a loop (buffer overflows).
- Exception unwinding through cache frames crashes in libunwind (personality pointer garbage); simple own @try/@catch works. Unresolved, avoid triggering exceptions.

- pkill -f macapps/macbins in stack scripts kills any ssh shell whose command line contains that word; poll with `pgrep -x Dock` instead.
- wsbsd `gmake check` has golden FAILs for 30001/30369/30370 caused by my earlier lenient replies (ca780f3/d8183b4); not fixed.
- Screenshots: after a VM reboot the console is BIOS VGA text mode (wsd -b kms fails: FBIOGTYPE); run `wsd -t -s /tmp/wsd.sock` (headless, 1280x800) and `WS_SOCKET=/tmp/wsd.sock wsshot /tmp/x.ppm`, then scp and convert.
